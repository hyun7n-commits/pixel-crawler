# 픽셀 던전 크롤러

녹픽던(Shattered Pixel Dungeon)식 턴제 던전에 뱀파이어 크롤러식 성장(골드, 상점, 유물 진화, 캐릭터 해금)을 합친 캐주얼 로그라이크입니다. 지금은 기획을 검증하기 위한 프로토타입 단계예요.

## 실행하기

브라우저 보안 규칙 때문에 `index.html`을 더블클릭하면 실행되지 않아요. 이 폴더에서 간단한 웹 서버를 띄운 뒤 브라우저로 열어 주세요.

```
python3 -m http.server 8000
```

그다음 브라우저에서 `http://localhost:8000`을 열면 돼요.

## 폴더 구조

| 경로 | 내용 |
| --- | --- |
| `src/data/` | 유물, 적, 캐릭터, 상점, 아이템, 밸런스 수치, 도트 그림. 코드를 몰라도 숫자와 글자를 바꿔 볼 수 있는 곳 |
| `src/core/` | 게임 규칙: 던전 생성, 전투, 턴, 성장, 저장 |
| `src/scenes/` | Phaser 화면: 타일과 캐릭터 그리기, 애니메이션, 파티클 |
| `src/ui/` | 마을 화면, 옆 패널, 선택 창 |
| `vendor/phaser.min.js` | 게임 엔진 Phaser 3.80.1 (MIT 라이선스, `vendor/PHASER-LICENSE.md`) |

규칙(`core`)은 화면을 전혀 모르고 이벤트만 보내요. 그래서 그래픽을 바꿔도 규칙은 그대로 둘 수 있어요.

## 조작

- 이동: 방향키, WASD, 대각선 Q E Z C, 또는 가고 싶은 칸을 클릭
- 공격: 적에게 부딪히기
- 쉬기: 스페이스
- 소모품: 1 물약, 2 폭탄, 3 지도
