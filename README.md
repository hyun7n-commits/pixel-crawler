# 픽셀 던전 크롤러

녹픽던(Shattered Pixel Dungeon)식 턴제 던전에 뱀파이어 크롤러식 성장(골드, 상점, 유물 진화, 캐릭터 해금)을 합친 캐주얼 로그라이크입니다. 지금은 기획을 검증하기 위한 프로토타입 단계예요.

## 실행하기

브라우저 보안 규칙 때문에 `index.html`을 더블클릭하면 실행되지 않아요. 이 폴더에서 간단한 웹 서버를 띄운 뒤 브라우저로 열어 주세요.

```
python3 -m http.server 8000
```

그다음 브라우저에서 `http://localhost:8000`을 열면 돼요.

## 폴더 구조

| 경로 | 내용 |
| --- | --- |
| `src/data/` | 유물, 적, 캐릭터, 상점, 아이템, 밸런스 수치, 도트 그림, 지형과 가스(`terrain.js`). 코드를 몰라도 숫자와 글자를 바꿔 볼 수 있는 곳 |
| `src/core/` | 게임 규칙: 던전 생성(`dungeon.js`), 지형 배치(`decorate.js`), 불·가스·폭발(`world.js`), 적의 상태와 행동(`ai.js`), 전투와 턴(`run.js`), 저장 |
| `src/scenes/` | Phaser 화면: 타일과 캐릭터 그리기, 애니메이션, 파티클 |
| `src/ui/` | 마을 화면, 옆 패널, 선택 창, 마우스 설명(`tip.js`) |
| `vendor/phaser.min.js` | 게임 엔진 Phaser 3.80.1 (MIT 라이선스, `vendor/PHASER-LICENSE.md`) |

규칙(`core`)은 화면을 전혀 모르고 이벤트만 보내요. 그래서 그래픽을 바꿔도 규칙은 그대로 둘 수 있어요.

## 조작

- 이동: 방향키, WASD, 또는 가고 싶은 칸을 클릭. 대각선은 방향키 두 개를 같이 누르거나 Q E Z C. 문을 포함해 어디서나 대각선으로 다닐 수 있어요(녹픽던 규칙)
- 공격: 적에게 부딪히기, 또는 적을 클릭하면 다가가서 한 번 때려요
- 쉬기: 스페이스
- 소모품: 1 물약, 3 지도
- 폭탄: 2를 누르거나 폭탄 버튼을 누른 다음 던질 칸을 클릭. 취소는 Esc
- 마우스를 칸 위에 올리면 그 칸에 무엇이 있는지 설명이 나와요
- 소리 켜고 끄기: M 또는 옆 패널의 소리 버튼. 효과음은 파일 없이 브라우저에서 바로 만들어요(`src/audio/sfx.js`)
- 화면: 마우스 휠로 확대 축소, 끌어서 둘러보기. 다시 움직이면 화면이 나에게 돌아와요

### 핸드폰 (v0.7.2, 녹픽던식 터치)

- 칸을 톡: 그 칸까지 걸어가요(대각선 포함, 되도록 곧은 길로). 새 적이 보이거나 맞으면 멈춰요
- 적을 톡: 붙어 있으면 때리고, 멀리 있으면 다가가서 한 번 때려요
- 나를 톡: 한 턴 쉬기
- 아무 칸이나 꾹: 그 칸 설명. 다음 톡은 설명만 닫아요
- 끌어서 둘러보기, 두 손가락으로 확대 축소
- 화면 배치: 위에 층·체력·골드, 아래에 쉬기, 물약, 폭탄, 지도, 가방. 유물과 소리, 포기하기는 가방 안에 있어요. 최근 메시지는 지도 아래쪽에 잠깐 떠요
- 화면은 기기의 실제 픽셀 밀도로 그려서 폰에서도 도트가 선명하고, 칸 크기는 한 줄에 약 10칸이 보이게 맞춰요

### 아이폰 (v0.8.1)

- 아이폰 Safari에 맞춰 두었어요: 화면 높이(`100dvh`), 두 손가락으로 페이지가 확대되거나 튕기지 않게, 꾹 눌러도 글자 선택이나 메뉴가 안 뜨게, 가로 화면에서 글자가 커지지 않게
- 소리는 손가락을 뗄 때마다 다시 켤 수 있으면 켜요. 전화나 다른 앱을 다녀와도 다시 나와요. 무음 스위치가 켜져 있으면 소리가 안 나요
- 공개 웹 주소에서 Safari로 열고 "홈 화면에 추가"하면 아이콘(`apple-touch-icon.png`)으로 앱처럼 전체 화면에서 돌아가요(`manifest.webmanifest`)
- 아이폰은 파일로 받은 .html을 미리보기로만 열어서 게임이 돌지 않아요. 아이폰에서는 웹 주소로 열어야 해요. itch.io에 올릴 때는 `index.html` 하나와 아이콘을 zip으로 묶어 HTML 게임으로 올리면 돼요

## 던전에 있는 것 (v0.7)

방과 문으로 이루어진 녹픽던식 층이에요. 문은 닫혀 있으면 안이 안 보이고, 누군가 서 있을 때만 열려요. 방마다 성격이 하나씩 있어요.

- 큰 광석 방: 층마다 하나. 부딪혀서 다섯 번 캐면 통째로 쏟아져요(골드 더미와 상자). 칠 때마다 소리가 커져서 자던 적이 깨어 찾아오고, 옆 틈에서 광산 가스가 새요
- 광석 등급 (v0.8): 동 → 은 → 금 → 다이아몬드 → 보석(에메랄드, 사파이어, 루비, 무지개석). 1~3층은 동, 4~6층은 은, 7~9층은 금에서 시작하고 가끔 한 등급 위로 나와요. 칠 때마다 속에서 다음 등급이 드러날 수 있어요(높은 등급일수록 어려움). 등급이 높을수록 골드 배율이 커지고, 뒤쪽 스윙일수록 골드가 많아요. 확률과 배율은 `src/data/balance.js`, `src/data/ores.js`
- 노다지: 스윙마다 3~6% 확률로 터져요. 그 스윙 골드 ×5, 등급도 한 단계 올라요
- 금 곡괭이(+5%/Lv)와 골드 러시, 황금 폭풍(+25%)은 등급이 오를 확률을 그대로 더해 줘서, 보석은 광석 빌드로 노리는 보상이에요
- 처음 보는 등급은 "새 광석!"으로 알려 주고, 마을 기록 탭의 광석 도감에 모여요
- 버섯 정원: 층마다 많아야 하나. 버섯 덤불(들어가면 숨음, 불에 잘 탐)과 졸음 버섯 한두 개. 여기 적은 푹 자고 있어서 몰래 치기 좋아요
- 물 찬 방: 웅덩이가 불을 꺼 주고, 번개는 물을 타고 퍼져요
- 졸음 가스: 나도 적도 잠들어요. 잠든 동안 코를 골아서 근처 적이 몰려오고, 잠든 상대에게는 바로 달려들어요. 맞으면 깨요
- 적: 처음에는 대부분 자고 있어요. 적을 줄이면 40턴마다 안 보이는 곳에서 새 적이 나타나 돌아다니다가 나를 만나면 덤벼요
- 광석 거북: 층마다 절반 확률로 있어요. 먼저 건드리지 않으면 싸우지 않지만, 튼튼하고 세요. 쓰러뜨리면 상자와 골드를 떨궈요
- 광산 가스: 불이 닿으면 이어진 가스가 한꺼번에 터져요
- 폭탄: 벽과 문을 부수고 불을 붙여요
- 계단: 내려가는 계단과 올라가는 계단이 있어요. 지나온 층은 떠날 때 모습 그대로 남아 있어서 돌아가 남은 것을 챙길 수 있어요. 보스 층은 보스를 쓰러뜨려야 위로 가는 길이 열려요
- 쫓아오는 적은 내가 지나온 칸을 그대로 밟아요. 그래서 뒤로 빠지면 거리가 유지돼요(녹픽던과 같은 방식)
- 적 머리 위 표시: 콧방울은 자는 중, "!"는 나를 발견, "?"는 나를 놓침, 땀방울은 도망, 내 칸의 빨간 발톱 자국은 다음 턴에 맞는다는 뜻이에요
- 새로운 조합을 찾으면 마을의 기록 탭 "발견 도감"에 남아요

## 유물 (v0.7)

- 기본 유물 19종(그중 7종은 마을 상점에서 사야 던전에 나와요), Lv1~3까지 올라가요
- 짝이 정해진 두 유물이 모두 Lv3이 되면 진화 유물 하나가 돼요(7종). 고르는 카드 중 하나는 보통 지금 가진 유물이나 그 짝이 나와서 진화를 노릴 수 있어요
- 진화 유물 두 개가 모이면 전설 유물이 돼요(3종). 조합은 처음엔 "???"로 가려져 있고 마을 소문과 기록 탭에서 힌트를 볼 수 있어요
- 기습: 나를 눈치채지 못한 적(자는 중, 어슬렁거리는 중, 찾는 중, 화나지 않은 광석 거북)을 치면 피해 ×2
- 문에서도 대각선으로 공격하고 걸어 다닐 수 있어요(v0.7.2부터 녹픽던처럼 대각선 제한이 없어요)

끈끈이, 독버섯, 수정, 광차, 금 간 천장, 구덩이, 갱목, 벽 광맥은 "빠르고 직관적인가" 기준에 맞춰 보류했어요. 게임 속 글은 모두 "~다" 체예요.
